# xrwvm-fullstack_developer_capstone

## Project Name: Cars Dealership - Full-Stack Web Application

A responsive web application for Cars Dealership, a national car retailer in the U.S.
Users can view dealership branches across the country, filter dealers by state,
read reviews of each dealer, and post their own reviews after logging in.

### Technologies
- Frontend: React, HTML, CSS, Bootstrap
- Backend: Django, Node.js / Express, Flask
- Databases: MongoDB, SQLite
- Sentiment analysis microservice
- Deployment: Docker, Kubernetes, IBM Cloud Code Engine
- CI/CD: GitHub Actions
